# Сарафан

> Игра про непрямое управление толпой на аниме-конвенте.
> **Ты — не распорядитель. Ты система навигации.** Ты управляешь информацией и пространством, а не людьми.

Прототип game-jam'а: симуляция толпы, где **игрок играет в настоящем, а толпа — в прошлом**. Агенты ходят по своим *убеждениям* о мире (где что находится, когда концерт, какой стенд сейчас на хайпе), и эти убеждения отстают от реальности. Ты вбрасываешь информацию, ставишь барьеры, гоняешь волонтёров — и смотришь, как сарафанное радио разносит правду и слухи по залу.

## Запуск

Чистый JS + ES-модули, без сборки. Нужен любой статический сервер:

```bash
cd GameJam_CVKBC
python3 -m http.server 8000
# открой http://localhost:8000
```

Тесты симуляции (без браузера):

```bash
node tests/run.js
```

## Ядро

- **Два времени.** Игрок действует мгновенно; толпа — по устаревшему знанию. Цвет агента = насколько он «отстал».
- **Аттракционы: хайп × качество.** У каждого стенда и события две оси. Хайп тянет толпу, качество скрыто. Распиаренная пустышка сливает удовлетворение и плодит слухи; реально крутое — восстанавливает радость и порождает евангелистов.
- **Сарафан.** Агенты разносят знание и слухи через диалоги: бутик-сплетни, фейк-ажиотаж, мета-приколы.
- **Частичное знание событий.** Толпа узнаёт о концерте не сразу — никаких телепатических набегов до твоего анонса. События могут переноситься сами.
- **Две метрики:** стресс и радость.
- **Честная навигация.** Поток-поля (Дijkstra по сетке) с клиренс-штрафом у стен, чтобы толпа держала центр прохода. Агент знает только о тех барьерах, что видел: упёрся в незнакомый барьер → мгновенно Lost → ищет обход и предупреждает других.

## Инструменты игрока

Перетаскивание любого NPC (общий кулдаун 10 с), барьеры (поставить/убрать), мобильный волонтёр-снижатель-стресса, конструктор табло, громкая связь, вброс слухов/приколов. Дев-панель для контроля симуляции.

## Структура

```
src/data/    tuning.js (весь баланс), map.js, events.js, messages.js
src/sim/     flowfield, steering, agent, knowledge, dialogue, special, lures
src/render/  draw.js
src/ui/      toolbar, boards, timeline, legend, inspector, finale
tests/       run.js
docs/superpowers/  специ и планы по итерациям (v1–v4)
```

Весь баланс — в `src/data/tuning.js`, весь контент — в data-файлах. Порт на Godot запланирован после джема.

## Итерации

- **v1–v2** — базовая симуляция, знание-по-убеждениям, очереди.
- **v3 «Живая экспо»** — физические POI, логистика, спецагенты, инциденты, инструменты игрока.
- **v4 «Хайп и сарафан»** — аттракционы хайп×качество, частичное знание событий, радость, таймлайн, слухи, мобильный волонтёр и лидеры групп.
